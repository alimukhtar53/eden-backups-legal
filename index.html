Eden Backups

Privacy Policy & Terms of Service — last updated 24 October 2026

Eden Backups is a private, single-user development application. It is not offered to the public, has no end users other than its owner, and is not distributed. This page exists to satisfy OAuth provider requirements for application registration.

1. What this application is

Eden Backups is an internal automation tool operated by a single individual. It mirrors database backup archives from a self-hosted object store (MinIO) to a private Google Drive folder owned by the same individual. The application is not listed publicly, has no sign-up, and accepts no users beyond its operator.

2. Information we access

The application requests the Google Drive scope solely to perform the mirroring described above. Specifically it:

  • Creates and reads files inside a single dedicated Drive folder
  • Reads file metadata (name, size, checksum) to verify transfers completed correctly

It does not read, scan, index, share, or transmit the contents of any other file in the operator's Google account.

3. How data is used and stored

  • Backup archives are copied from the operator's own MinIO instance to the operator's own Google Drive.
  • No data is copied to, processed by, or stored on any third-party server.
  • OAuth credentials are stored locally on the operator's machine with restricted file permissions.
  • No analytics, tracking, telemetry, or advertising is used.

4. Data sharing

No data is sold, rented, shared, or disclosed to any third party. The application communicates only with Google's APIs and the operator's own infrastructure.

5. Data retention and deletion

Retention is controlled entirely by the operator, who may delete mirrored files from the Drive folder at any time. Revoking the application's access from the Google Account permissions page immediately and permanently ends all access.

6. Security

Transfers use HTTPS in both directions and are verified by checksum after completion. Credentials are never committed to source control.
